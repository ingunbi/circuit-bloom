# Circuit Bloom

회로 조각을 돌려 작은 전자 정원에 꽃을 피우는 브라우저 퍼즐입니다. 시간 제한 없이 연결을 생각하는 짧은 휴식용 게임입니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```powershell
npm ci
npm run dev
npm run test
npm run build
npm run preview
```

`dist/`가 독립 정적 웹사이트이며, Vite의 상대 경로 설정으로 포털의 `/games/circuit-bloom/` 하위에서도 실행됩니다. `wrangler.jsonc`는 Cloudflare 정적 배포용 설정입니다.

## 플레이

- 타일을 클릭하거나 터치하면 시계 방향으로 90도 회전합니다.
- 빛나는 시작점은 고정되어 있습니다. 서로 마주 보는 선을 이어 모든 타일에 전원을 전달하면 꽃이 피고 정원을 완성합니다.
- 방향키로 타일 사이를 이동하고 Enter/Space로 회전합니다. `P`/`Esc`는 일시정지, `M`은 소리 전환입니다.
- 도움은 한 타일을 정답 방향으로 맞춥니다. 도움을 사용한 퍼즐은 완성할 수 있지만 최고 기록에는 남지 않습니다.
- 4×4부터 5×5, 6×6까지 정원 난도가 커집니다. 다음 정원과 최고 기록은 브라우저에 저장됩니다.
- **오늘의 정원**은 한국 시간 자정을 기준으로 매일 바뀌는 동일 시드의 5×5 퍼즐입니다.
  열린 화면도 날짜가 바뀌면 새 퍼즐로 갱신하며, 절전·백그라운드에서 돌아올 때도 날짜를 확인합니다. 일시정지와 도움말 상태는 유지됩니다.

## 구현 및 검증

외부 에셋, 폰트, 계정, 백엔드 없이 작동합니다. 회로는 먼저 DFS 생성 트리로 정답을 만든 뒤 회전하므로 모든 보드가 풀립니다. 전원은 서로 마주 보는 연결에만 전달되며 모든 타일이 켜져야 완성됩니다. `node:test`가 3·4·5·6·8 크기의 총 500개 시드에서 정답 연결성, 초기 미완성, 회전 가능성을 확인합니다. KST 일일 시드·자정 타이머·백그라운드 복귀, 저장값 유효성·캠페인 진도·도움 사용 시 기록 제외도 검사합니다. 사운드는 사용자 입력 후 WebAudio로 합성합니다. 저장소/오디오 사용이 제한돼도 퍼즐은 실행됩니다.

개발 서버의 `/tests/browser.html`은 브라우저 회귀 확인용입니다. 실제 게임 모듈에 테스트 전용 시계를 적용하여 날짜 전환·일시정지·도움말·키보드 포커스와 999→1000단계 진행을 확인할 수 있습니다. 테스트 기록은 별도 저장 키를 사용하며, 이 페이지는 프로덕션 빌드에 포함되지 않습니다.
