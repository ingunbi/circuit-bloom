# Circuit Bloom

회로 조각을 돌려 작은 전자 정원에 꽃을 피우는 브라우저 퍼즐입니다. 시간 제한 없이 연결을 생각하는 짧은 휴식용 게임입니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```powershell
npm ci
npm run dev
npm run test
npm run build
npm run preview
```

`dist/`가 독립 정적 웹사이트이며, Vite의 상대 경로 설정으로 포털의 `/games/circuit-bloom/` 하위에서도 실행됩니다. `wrangler.jsonc`는 Cloudflare 정적 배포용 설정입니다.

## 플레이

- 왼쪽·오른쪽 방향을 고른 뒤 타일을 클릭하거나 터치하면 해당 방향으로 90도 회전합니다. 역회전도 1회로 셉니다. 우클릭이나 `Shift+클릭`은 선택 방향의 반대로 돌립니다.
- 빛나는 시작점은 고정되어 있습니다. 서로 마주 보는 선을 이어 모든 타일에 전원을 전달하면 꽃이 피고 정원을 완성합니다.
- 방향키로 타일 사이를 이동하고 Enter/Space로 회전합니다. `P`/`Esc`는 일시정지, `M`은 소리 전환입니다.
- 타일에 포커스한 상태에서 `Q`는 왼쪽, `E`는 오른쪽 회전입니다. `F`는 타일 고정·해제입니다. 고정 모드를 켜면 모바일에서도 탭으로 고정·해제할 수 있습니다.
- 고정한 타일은 직접 회전과 도움으로 바뀌지 않습니다. 고정·해제는 회전 수를 늘리지 않으며 되돌리기·다시 하기와 자동 저장에 포함됩니다.
- `Z`로 되돌리고 `Y`로 다시 실행합니다. `Ctrl+Z`와 `Ctrl+Shift+Z`도 지원합니다. 새 회전을 하면 다시 하기 이력이 초기화됩니다.
- 도움은 한 타일을 정답 방향으로 맞춥니다. 도움을 사용한 퍼즐은 완성할 수 있지만 최고 기록에는 남지 않습니다.
- 도움을 되돌려도 해당 시도의 도움 사용 여부는 유지됩니다. 처음 모양으로 다시 시작하면 새 시도가 됩니다.
- **연습**에서 세 조각을 직접 연결하며 규칙을 익힐 수 있습니다. 연습은 실제 회로·최고 기록·모은 꽃에 영향을 주지 않습니다.
- 4×4부터 5×5, 6×6까지 정원 난도가 커집니다. 다음 정원과 최고 기록은 브라우저에 저장됩니다.
- 진행 중인 회로·회전 수·되돌리기 이력도 자동 저장합니다. 새로고침하거나 캠페인·일일·자유 모드를 오가도 각 판을 이어 갈 수 있습니다.
- **자유 정원**에서 4×4·5×5·6×6 크기와 씨앗 이름을 골라 새 퍼즐을 만듭니다. 같은 크기와 이름은 항상 같은 회로를 만들며, 새 씨앗 버튼으로 이름을 뽑을 수도 있습니다. 이름은 공백 정리·NFC 정규화 후 1~40글자이며 제어 문자는 받지 않습니다.
- 보드 아래 **…** 도구 메뉴에서 처음부터 시작·퍼즐 공유·새 정원을 엽니다. 공유 화면은 코드를 먼저 보여 주며 링크는 접힌 메뉴에서 열 수 있습니다. 받은 코드는 자유 정원의 **코드로 열기**에 붙여 넣습니다. 회전·고정·도움 사용 이력은 공유되지 않습니다.
- 공유받은 캠페인·일일 퍼즐도 자유 정원으로 열립니다. 원래 회로는 같지만 기록은 분리되며 캠페인 해금이나 일일 연속 기록을 바꾸지 않습니다. 자유 정원 완성 수와 모은 꽃은 전체 모음에 합산합니다.
- 자유 정원은 마지막 한 판을 이어 갈 수 있습니다. 새 자유 정원을 열면 그 슬롯이 바뀌며, 이전 씨앗은 보관함이나 공유 코드로 다시 풀 수 있습니다. 잘못된 코드나 링크는 현재 진행을 지우지 않습니다.
- **정원 → 씨앗 보관함**에서 최근 씨앗과 즐겨찾기를 다시 열 수 있습니다. 자유 정원 이름 옆 별표로 즐겨찾기를 바꾸며, 이름·크기로 검색할 수 있습니다. 최근 40개와 즐겨찾기 20개를 보관합니다.
- 현재 진행 중인 씨앗은 보관함에서도 이어하기로 열리고, 다른 씨앗은 처음 배치부터 시작합니다. 보관함에서 제거해도 진행·완료·최고 기록은 유지되며 재방문 시 다시 목록에 표시됩니다.
- 상단 **정원**에서 열린 정원을 다시 고르고 누적 기록을 볼 수 있습니다. 이전 정원을 다시 완성해도 최고 해금 진도는 유지됩니다. 현재 판의 기준·최고 기록·획득한 꽃은 보드 아래 **이 정원 기록**을 펼쳐 확인합니다.
- 완성하면 꽃 1~3송이를 모읍니다. 도움 없이 설계 기준 이내는 3송이, 기준의 1.5배 이내는 2송이, 그 밖의 완성이나 도움을 쓴 시도는 1송이입니다. 각 정원의 최고 꽃 수만 모음에 반영하며, 설계 기준은 최적해를 보장하지 않습니다.
- 설계 기준은 준비된 정답까지 왼쪽·오른쪽 중 짧은 방향을 골라 맞추는 회전 합입니다. 기존에 저장된 회전 수와 획득한 꽃은 소급 변경하지 않습니다.
- 상단 기록에서 완성한 정원 수, 모은 꽃, 한국 날짜 기준 일일 연속 완성 기록을 볼 수 있습니다. 기존 최고 기록은 꽃 1송이를 모은 완료 기록으로 이어집니다.
- **오늘의 정원**은 한국 시간 자정을 기준으로 매일 바뀌는 동일 시드의 5×5 퍼즐입니다.
  열린 화면도 날짜가 바뀌면 새 퍼즐로 갱신하며, 절전·백그라운드에서 돌아올 때도 날짜를 확인합니다. 일시정지와 도움말 상태는 유지됩니다.

## 구현 및 검증

외부 에셋, 폰트, 계정, 백엔드 없이 작동합니다. 회로는 먼저 DFS 생성 트리로 정답을 만든 뒤 회전하므로 모든 보드가 풀립니다. 전원은 서로 마주 보는 연결에만 전달되며 모든 타일이 켜져야 완성됩니다. `node:test`가 3·4·5·6·8 크기의 총 500개 시드에서 정답 연결성, 초기 미완성, 회전 가능성을 확인합니다. 양방향 회전 기준은 4·5·6 크기 총 300개 보드의 정답 복원으로 검증합니다. KST 일일 시드·자정 타이머·백그라운드 복귀, 저장값 유효성·캠페인 진도·도움 사용 시 기록 제외·꽃 평가·일일 연속 기록·되돌리기/다시 하기·고정·음수 회전 이력·기존 세션 복원도 검사합니다. 사운드는 사용자 입력 후 WebAudio로 합성합니다. 저장소/오디오 사용이 제한돼도 퍼즐은 실행됩니다.

기존 저장 키 `circuit-bloom.v1`은 호환성을 유지하며 완성 꽃 기록을 확장합니다. 진행 중인 판은 별도 `circuit-bloom.sessions.v1` 키에 저장합니다. 저장된 판은 시드와 회전 이력을 검증해 원본 퍼즐로부터 복원하고, 다른 날짜나 손상된 이력은 새 판으로 대체합니다.

씨앗 보관함은 `circuit-bloom.library.v1`에 따로 저장합니다. 처음에는 기존 자유 정원 완료 기록과 마지막 자유 씨앗에서 보관함을 복원합니다. 이전에 완료하지 않고 떠난 씨앗은 기존 저장 정보가 없으므로 복원 대상에 포함되지 않습니다.

진행 상황과 검증 결과는 [개발 기록](DEVLOG.md)에 한국어로 남깁니다. 자동 검증의 검사 설명도 한국어로 작성합니다.

공유 형식은 `CB1.` 접두사의 UTF-8 JSON/base64url 코드입니다. 크기·이름·날짜·버전·길이를 검증하며, 자유 복제판은 원래 시드로 생성한 뒤 `free:CB1...` 기록 키를 사용합니다. `#puzzle=코드` 링크는 현재 게임의 루트 경로를 유지하므로 포털 하위 경로에서도 사용할 수 있습니다. 링크를 한 번 열면 주소의 공유 해시를 정리하여 이후 모드 선택과 새로고침을 방해하지 않습니다. 로컬 주소는 다른 기기에서 열리지 않을 수 있으므로 이때는 퍼즐 코드로 공유합니다.

개발 서버의 `/tests/browser.html`은 브라우저 회귀 확인용입니다. 실제 게임 모듈에 테스트 전용 시계를 적용하여 날짜 전환·일시정지·도움말·보관함·키보드 포커스와 999→1000단계 진행을 확인할 수 있습니다. 테스트 기록은 별도 저장 키를 사용하며, 이 페이지는 프로덕션 빌드에 포함되지 않습니다.

`/tests/responsive.html`에서는 실제 게임을 320·390·760px 너비의 프레임으로 열어 반응형 배치와 조작 버튼을 확인할 수 있습니다. 이 페이지도 프로덕션 빌드에서 제외됩니다.
